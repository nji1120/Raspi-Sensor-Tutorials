# HC-SR04

たぶん一番定番の距離センサ  

## リンク集  
- [秋月ページ](https://akizukidenshi.com/catalog/g/g111009/)  
- [使い方記事](https://raspi-school.com/ultrasonic-sensor/)

## 仕様
| 項目             | 仕様            |
| :--------------- | :-------------- |
| 定格             | 3~5.5V          |
| 測定範囲         | 0.02m ~ 4.5m    |
| インターフェース | GPIO, I2C, UART |
| 動作温度         | -10~70℃         |

## ピン説明

| pin  | description                                  |
| :--- | :------------------------------------------- |
| VCC  | 3~5.5V                                       |
| Trig | 10μs以上highにすると超音波発信               |
| Echo | 超音波の発信終了から受信までhigh(3.7V)を出力 |
| GND  | グランド                                     |

## 使い方
1. Trigを10μs以上highにする  
   → 超音波の発信開始
2. Echoがhighの時間$t$を計測  
   → 超音波が返ってくるまでhighになる  
3. 音速$v$と計測時間$t$から距離$d$を計算  
   $d = (v \times t)/2$  
   ※ここで2で割っているのは往復を考慮するため
